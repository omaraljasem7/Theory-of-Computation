("A" ≠ "B" , das letzte Zeichen ist  "A" die Auswertung ergibt true ) Schleife wird abgearbeit 
("C" ≠  "B", das letzte Zeichen ist "C" die Auswertung ergibt true )  Schleife wird abgearbeitet 

was akzeptiert das Programm also wann ergibt er true ?
